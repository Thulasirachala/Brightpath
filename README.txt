# BrightPath Solutions Web Prototype

Open `index.html` in a browser to start.

Pages:
- index.html — Home
- about.html — About
- services.html — Services
- request.html — Customer request form
- login.html — Prototype login
- customer-dashboard.html — Customer dashboard
- admin-dashboard.html — Admin dashboard
- contact.html — Contact
- css/style.css — Design
- js/script.js — Prototype interactions

Note: This is a front-end prototype. Login, database, payments and real admin authentication are not connected yet.
